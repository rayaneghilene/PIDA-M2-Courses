# Political Ideas in a Digital Age Master Program Second Year Courses

Course Materials for Second Year [PIDA Master students at CY Cergy Paris University](https://formation.cyu.fr/fr/offre-de-formation/master-grade-master-XB/master-etudes-europeennes-et-internationales-eei-MCEHF7TU/master-eei-parcours-political-ideas-in-a-digital-age-PAR231.html)

The materials for each class will be added as the course progresses. Class discussions and any instructions given in class take precedence over this overview.

## Getting started

Open the slides for the relevant class before or after the session.

For practical exercises, open the provided notebook in Google Colab or another Jupyter environment. You can use Colab in a browser without installing Python locally.

Make a personal copy of a notebook before editing it, so your work is saved in your own account.

Try the exercises yourself. It is fine if a program does not work on the first attempt: reading errors and revising your code are part of learning.



## How to use this repository

Slides introduce the ideas and vocabulary. Notebooks and exercises give you a chance to apply them. Optional resources are there if you want to go further; they are not a substitute for what we discuss in class.

You are welcome to revisit the materials at your own pace. If something is unclear, bring your question to the next class.
